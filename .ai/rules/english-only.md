# English Only

All new or modified repository content must be written in English.

- Use English for source code, identifiers, filenames, comments, PHPDoc, tests, configuration, documentation, and commit messages.
- Do not add new Persian text to the codebase unless the task explicitly requires product-facing Persian content or localization data.
- Preserve existing localized content when it is outside the current task; do not translate unrelated files.
- Conversation responses may follow the user's language.
